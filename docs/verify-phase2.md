# Phase 2 手动验证清单（键鼠注入 + 保命措施）

> **为什么需要你手动做**：自动化测试全部跑在 **dry-run** 下（只记录、不执行），
> 因为开发机就是被控机 —— 测试里真注入的话，一旦有 bug 就会夺走你自己的键鼠。
> 所以下面两件事只能由你在可接受的风险下亲自验一次：
>
> 1. **急停热键真实按键** —— 我没法替你按键
> 2. **真实注入** —— 需要在你的键鼠上实际发生

---

## 前置：先看只读模式（零风险）

先确认只读模式依然安全：

```powershell
# 终端 1：中继
.\.venv\Scripts\python.exe src\relay\server.py --no-tls --port 18443 `
    --token <relay_token> --room <room>

# 终端 2：Agent（保持 allow_input = false）
.\.venv\Scripts\python.exe src\agent\main.py --config config.toml

# 终端 3：Viewer
.\.venv\Scripts\python.exe src\viewer\main.py --config config.toml
```

在 Viewer 窗口里动鼠标、点几下、敲几个字。然后看 **Agent 终端**：

```
[只读] 已忽略 51 个键鼠事件（allow_input=false）
```

✅ **本机鼠标键盘必须完全没反应**。如果本机跟着动了，说明有 bug，立刻告诉我。

---

## 第 1 步：演练模式（dry-run）—— 零风险验证注入链路

这一步让整条链路真跑起来，但注入器只**记录**不执行。

```powershell
# 终端 2：Agent 改成可注入 + 演练模式
.\.venv\Scripts\python.exe src\agent\main.py --config config.toml --allow-input
```

同时把 `config.toml` 里设上：

```toml
[agent]
allow_input = true
input_dry_run = true      # ← 只记录，不真的操作键鼠
```

（也可以用环境变量临时开：`$env:ALSPD_INPUT_DRY_RUN="1"`）

Agent 启动时会打印：

```
[注入] ⚠️ 演练模式（dry-run）：只记录应该注入什么，**不会真的操作本机键鼠**。
[急停] 热键已注册：ctrl+alt+shift+q  —— 按下即停止注入并断开远程会话
```

然后在 Viewer 窗口里随便动鼠标、点击、滚动、打字。**本机键鼠应当毫无反应**（因为是演练模式）。Agent 的 5 秒状态日志里会出现：

```
[统计] 键鼠：注入 N 次，被保护逻辑拦下 M 次
[统计] 注入明细：移动 N / 点击 N / 滚轮 N / 按键 N，本机活动检测触发 0 次，SendInput 失败 0 次
```

✅ **要看的**：数字在涨、且本机键鼠没动 → 说明事件从 Viewer 一路正确走到了注入器。

❌ **如果 `SendInput 失败` 次数在涨**：注入被系统拒绝了（常见于目标窗口以管理员权限运行，而 Agent 不是）。需要以管理员身份运行 Agent。

## 第 2 步：真实验证急停热键 ⚠️

这一步会真的注入，**但只做一件无害且可逆的事**：把光标移到一个位置再移回来。

```powershell
# 终端 2：真实注入模式（去掉演练）
# config.toml: input_dry_run = false
.\.venv\Scripts\python.exe src\agent\main.py --config config.toml --allow-input
```

**先做这个（重要）**：一启动就**立刻按一次 `Ctrl+Alt+Shift+Q`**，确认：

1. Agent 终端打印：
   ```
   [保命] 🔴 急停：停止注入、松开按键、停止 Agent（需手动重启才能再用）
   [保命] ▶  已暂停键鼠注入：急停热键被按下
   ```
2. **Agent 进程直接退出**（不会自动重连）

✅ 这一步过了，你就有了一颗随时能按的"刹车"。**这之后再往下走。**

> 急停是**刻意的彻底停止**：只断线的话 Agent 会自动重连、Viewer 一回来注入就恢复，
> 那急停就没意义了。要再用必须手动重启 Agent。

❌ **如果提示 `热键注册失败`**：说明这个组合被别的程序占用了。改 `config.toml` 里的
`panic_hotkey`（比如换成 `ctrl+alt+shift+f12`）后重启 Agent。

## 第 3 步：真实的键鼠注入

**确认第 2 步的急停热键好使之后**再做这一步。

```powershell
# 终端 2
.\.venv\Scripts\python.exe src\agent\main.py --config config.toml --allow-input

# 终端 3
.\.venv\Scripts\python.exe src\viewer\main.py --config config.toml --enable-input
```

> Viewer 的键鼠注入**默认是关闭的**，必须显式加 `--enable-input`。
> 界面上会显示 `⚠️ 键鼠注入：已启用`。

然后：

1. **先只动鼠标看位移** —— 在 Viewer 窗口里慢慢移动，本机光标应当跟着动，位置要对得上（点哪到哪）
2. **再试单击** —— 点一个空白区域，看是否点中
3. **再试键盘** —— 打开记事本，敲几个字母，看是否出现正确字符
4. **试滚轮** —— 在长网页里滚

### 本机活动检测

注入开着的时候，**用手动一下本机的鼠标**（或鼠标垫）。Agent 应当立刻打印：

```
[保命] ⏸  已暂停键鼠注入：检测到本机有人在操作鼠标（实际 (x,y)，预期 (x,y)）—— 把控制权让给本机
```

并把控制权让给你。安静 `input_guard_auto_resume` 秒后自动恢复。

✅ 这个机制让你随时能"抢回"控制权，不用去按热键。

### 位置对不上怎么办

- **多显示器**：先确认 Agent 在**主屏**上采集（`output` 留空）。副屏 + dxcam 无法确定显示器偏移，Agent 启动时会警告。
- **缩放（DPI）**：用的是归一化坐标，理论上不受影响；若偏差固定，告诉我。

## 第 4 步：剪贴板同步

**不需要开注入**，剪贴板是独立功能（默认开启）。

在 Viewer 窗口里正常操作的同时：

1. 在**家里这台**上复制一段文本（Ctrl+C）→ 到**公司那台**上粘贴，看内容对不对
2. 在**公司那台**上复制一段文本 → 到**家里这台**上粘贴
3. 多来回几次，确认**不会互相覆盖**（不该出现"两边来回刷同一个内容"的现象）

Agent 的统计日志会显示：

```
[统计] 剪贴板：发送 2 次 / 应用 2 次 / 过大跳过 0 / 写入失败 0
```

不想要剪贴板同步就加 `--no-clipboard`（Viewer）或在 Agent 配置里设 `clipboard_sync = false`。
