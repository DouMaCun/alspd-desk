Why

问题不在功能，在信任

远程办公需要连回公司电脑。但把桌面画面交给商业远控工具，意味着你的屏幕内容、键鼠操作 都要经过别人的服务器。桌面上一旦有敏感资料，这个风险不好接受。

⚠️

第三方远控工具

画面与输入经过厂商服务器，你只能「相信」它不记录、不外泄、不被入侵。
中间任何一环出问题，你都无法察觉。

🔒

ALSPD-DESK

中继是你自己的 VPS，而且拿不到解密密钥。 就算 VPS 被入侵、被扣押，攻击者得到的也只是密文。

Architecture

两端主动外连，被控机不开任何端口

被控端和家里那台都主动连出去到你的 VPS。所以不必改防火墙、 不必做端口映射、也不需要管理员权限。

Security model

中继拿不到解密所需的东西

这是整个项目最核心的一个设计决定：把「配对身份」和「加密密钥」拆成两个独立的秘密。

秘密谁知道用途
relay_token Agent / Viewer / 中继 向中继证明身份 —— 只能用于配对，不能解密
password Agent / Viewer
从不发给中继		 派生端到端会话密钥，真正保护画面内容
PSK = Scrypt(password, salt) # 密码不当密钥直接用
session = HKDF(PSK, agent_nonce ‖ viewer_nonce) # nonce 明文交换无妨

两个 nonce 由双方随机生成、经中继明文交换（nonce 本身无需保密）。 但中继没有 PSK，无法派生出会话密钥。

🛡️

抗重放

每帧带序列号 + GCM nonce 计数器，重放旧密文会被直接拒绝。

🎭

TLS 只是伪装层

就算公司做了 TLS 中间人解密，解出来的仍是我们的密文，机密性不受影响。

🔑

AES-256-GCM

会话密钥一次性、由双方 nonce 派生；换一次会话就换一次密钥。

Safety

⚠️ 它会夺取键鼠，所以要有刹车

被控端的职能就是操作键鼠 —— 代码有 bug 时可能夺走你自己的键鼠。 所以内置了四层保护，默认全部开启。

🛑

1 · 急停热键 Ctrl+Alt+Shift+Q

按下即暂停注入 + 松开所有按键 + 彻底停止 Agent（连重连也停掉，需手动重启）。

👁️

2 · 只读模式

allow_input = false 时根本不创建注入器 —— 只上传画面。

⏱️

3 · 空闲自动断连

远程无操作超时后自动断开，并松开所有按键。

🖱️

4 · 本机活动检测

发现本机有人在动鼠标 → 立即暂停注入，把控制权让给本机的人。

🧪

外加一个演练模式

input_dry_run = true 时只记录「本来会注入什么」， 不真的操作键鼠 —— 可以安全地验证整条注入链路，不用担心失控。 项目所有自动化测试也跑在这个模式下。

Quick start

三步跑起来

需要一台有公网 IP 的 VPS（Debian / Ubuntu）和两台 Windows。

1

在 VPS 上部署中继

# 上传代码（从你的开发机）
scp -r src config.relay.example.toml root@<你的VPS_IP>:/opt/alspd/

# 在 VPS 上：中继只依赖 websockets 一个库
cd /opt/alspd
mv config.relay.example.toml config.relay.toml   # 填好 room / relay_token
pip3 install --break-system-packages websockets
python3 src/relay/server.py --config config.relay.toml
2

在被控端（公司电脑）运行 Agent

# 先自检：不联网、不注入键鼠
.\ALSPD-Agent.exe --selftest

# 启动
.\ALSPD-Agent.exe --config config.toml
3

在控制端（家里电脑）运行 Viewer

# 只看画面（推荐先用这个确认链路）
ALSPD-Viewer.exe

# 确认稳定后，想操作键鼠再加
ALSPD-Viewer.exe --enable-input
📋

动手前建议先做一次网络侦察

tools/probe_agent.py 会告诉你：能不能跑未签名程序、 哪些端口通、TLS 有没有被中间人、哪个代理可用、真实带宽多少。 在锁定的办公网络里，这一步能避免白忙一场。

Limitations

如实说清楚它做不到什么

这是个个人自用工具，不是产品。下面这些限制是真实存在的，不是客套话。

  • 全走中继，未实现 P2P 直连 —— 延迟和带宽取决于你的 VPS，多一跳。
  • 用户态运行，不控制登录界面 / UAC 提权窗口 —— 这是刻意的取舍：这样就不需要管理员权限。代价是锁屏后无法远程解锁。
  • 多块显示器分辨率完全相同时无法区分 —— 此时会明确警告并拒绝猜测（注入位置错了比不注入更糟）。
  • 剪贴板只支持纯文本，不含图片 / 文件。
  • 未做文件传输。
  • 链路质量取决于你的网络 —— 实测遇到过突发丢包导致的 0.5~2 秒延迟尖峰。
  • 未经过安全审计。请自行评估风险。
